# Guru Kripa Astrology & GemsTone 💎🕉️

100% Certified Natural Vedic Gemstones & Astrology Consultations E-Commerce Platform.

## 🚀 Overview
A complete, production-grade E-Commerce & Vedic Astrology consultation platform comprising:
- **Frontend**: Customer shopping portal, 100% Free Janampatri & Kundli consultation, WhatsApp & direct hotline integrations.
- **Admin Panel**: Complete back-office management for Orders, Products, Banners, Customers, Vedic Inquiries, and Delivery tracking.
- **Backend**: Express + Node.js + TypeScript REST API with MongoDB, JWT Authentication, and Razorpay payment gateway.

---

## 📂 Project Structure
```text
GuruKripaAstrologyGemsTone/
├── Frontend/      # React (Vite) + Tailwind CSS + Redux customer portal
├── Admin_panel/   # React (Vite) + Tailwind CSS admin management dashboard
└── Backend/       # Express + TypeScript + MongoDB REST API server
```

---

## 🛠️ Tech Stack
- **Frontend & Admin**: React 18, Vite, TypeScript, Tailwind CSS, Framer Motion, Redux Toolkit, React Query.
- **Backend**: Node.js, Express, TypeScript, Mongoose (MongoDB), Multer, JWT, Razorpay SDK.
- **Database**: MongoDB Atlas.

## ⚙️ Quick Start (Local Development)

### 1. Backend Setup
```bash
cd Backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd Frontend
npm install
npm run dev
```

### 3. Admin Panel Setup
```bash
cd Admin_panel
npm install
npm run dev
```
